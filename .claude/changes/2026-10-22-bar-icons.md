## What changed
- Every dwmblocks block script except dwm-clock and dwm-dnd prints a Nerd
  Font glyph (Material Design set, from the vendored Cascadia Code NF)
  instead of its text label: 󰏗 updates, 󰋊 disk, 󰔏 temp, 󰻠 cpu, 󰍛 mem,
  󰃟/󰛨 gamma/backlight, 󰍬/󰍭 mic, 󰕿󰖀󰕾/󰝟 volume, 󰤯…󰤨/󰖩/󰈀/󰤮/󰛳 net,
  󰂲/󰂯/󰂱 bluetooth, 󰂎…󰁹/󰂄 battery.
- State-aware icons: volume waves at WAVES_2=34 / WAVES_3=67, Wi-Fi bars
  per 20 points of signal, battery filled to the nearest tenth (`set --` +
  `shift`), charging icon replacing the old `+`.
- Compact values: disk without "free", memory used only (total still read
  to reject a bad reading), temperature `°` not `°C`, no SSID (nmtui on a
  left-click shows it), and mic/volume/bluetooth muted/off as the icon alone.
- Tests updated: tests/blocks-{audio,info,system,battery}.sh,
  tests/dwm-net.sh (a signal-bars table and a no-signal case replace the
  SSID unescape/truncate cases). KEYBINDINGS.md bar table + prose,
  docs/HARDWARE.md, CHANGELOG [Unreleased], CLAUDE.md, blocks.def.h comment.

## Why
User request: "switch the text on bar to icons". Layout chosen from three
previews: "Icon + compact value", state-aware icons, clock not compacted.

## Assumptions Made
- Type B: the backlight/gamma distinction the old BL/GAMMA labels carried
  is kept as two icons: the lamp 󰛨 for a real backlight, the sun 󰃟 for
  xrandr gamma (which saves no power).
- Type B: `n/a` stays as text beside the icon, so "unknown" stays distinct
  from "off" (which is the icon alone).
- Type B: the clock gets no icon (the chosen preview had none; the user
  asked for it not to be compacted).
