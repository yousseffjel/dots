## Why
The user asked what would make dots feel like an integrated desktop. A
Secret Service was first on the list because its absence is silent:
Chromium-based browsers, VS Code and git credential helpers store secrets in
plain text when nothing answers `org.freedesktop.secrets`.

The slot came out much smaller than planned. ly's stock PAM file at the
pinned commit `afb1dc6` (`res/pam.d/ly-linux`, read from a shallow fetch)
already has `-auth`/`-password`/`-session optional pam_gnome_keyring.so`
(`auto_start` on session). That file is installed as `/etc/pam.d/ly`, a
LYBUILD row. The leading `-` skips a missing module, so installing the
package turns the unlock on, and a ly rebuild places the same lines. The
scope file's "who owns /etc/pam.d/ly, and how does an edit survive a
rebuild" therefore needs no answer. gnome-keyring-48.0_1's file list
(the `.xbps`, read 2026-10-23) has `org.freedesktop.secrets.service`, so
bus activation starts the secrets component. That removes any session line,
and existing installs need nothing pasted.
