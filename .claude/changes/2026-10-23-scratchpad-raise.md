## Why
User report: on monitor 1, Super+s on a tag that already had windows did
not open the scratchpad, while on a free tag it did; monitor 2 worked.
It did open, focused, but UNDER the tiled windows: `arrange(NULL)` (unlike
`arrange(m)`) never calls `restack()`, so a member kept its old X stacking
position. Monitor dependence: `restack()` puts each monitor's tiled windows
directly below that monitor's bar, and the right bar (made second) is above
the left one, so which window wins depends on where each was last restacked.

## Assumptions
- Type B: raise every member, not only the focused one (they do not
  overlap in the layout; all should be visible).
- Type C: the hiding branch's `arrange(NULL)` left alone; no visible effect.
