  `patches/dwm-wakeonsignal-20261012-local.diff` + PATCHES.md, rule 5).

## Why
This was the planned on-hardware check of scope F (slot 4). A sandbox, a
container and Xvfb had each passed every item, and none could see what a
live, idle session showed:
- an idle desktop sends no X event, so dwm sat on a signal for 20-25 s;
- xss-lock aborts when X goes away under it;
- the doctor ordering hid a missing one-shot;
- `nmtui` is a separate package nobody declared, and the dwm-net test
  faked it.

The user chose each fix (D1-D4, 2026-10-12). D1 swapped pselect for a
self-pipe, because blocking signals would be inherited by every client
dwm spawns.
